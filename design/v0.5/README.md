## 版式

- 主画板 1280×800；外边距 32；卡片间距 12；卡片圆角 16。
- 全屏自适应：宽屏两栏（主区 + 右栏），窄屏 900 单栏。
- 顶部 64px：品牌 / 日期 / 状态 / 开工 / 收工 / 设置。
- Hero 196px：大金额、进度条（70/90/100 刻度）、剩余额度、预计用完时间、自由时间。
- 两个账本卡片：工作（Claude Code，计入）与工具（DSH，不计入）。
- 近 7 天工作账本：柱状图 + ¥10 上限线。
- 今日请求：时间 / 项目 / 模型 / 成本。
- 设置：右侧 440px 抽屉，覆盖在暗化仪表盘上。

## 字体

- `Noto Sans TC`，400 / 500 / 600 / 700。
- 页面标题 20；Hero 金额 44；卡片标题 12–13；正文 10–12；辅助 8–9。
- 数字使用表格数字（等宽），金额保留 2 位。

## 关键规则

- 预算只约束 **工作账本**（Claude Code）；DSH 工具账本只展示、不参与进度。
- 进度刻度固定在 70% / 90% / 100%；LOCKED 时进度条变红并显示「已用完」。
- 收尾模式：¥0.50 / 30 分钟；收尾清单区分允许与拒绝的操作。
- 设置抽屉包含预算、校准、价目表、hooks、二级上限、数据操作；危险操作需二次确认。
- 不做 CPU / 系统监控；不做托盘 / 窄侧栏。
