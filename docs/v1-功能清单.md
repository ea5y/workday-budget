# v1 功能清单（公司机 · 单机版）

> 2026-11-04 · 对应需求文档 v0.6 · 界面见 Penpot「工作日预算器 · GUI」

## 0. 范围

**做**：公司机 Windows、只读 Claude Code 会话日志、单一 `work` 账本、CLI + 状态栏 + **GUI 面板**。
**不做**：排期、溢出报告、资讯简报、双机同步、个人时间块、手机端。

> 手机端明确不做：账本与执行点都在本机，上手机就得先有服务端同步，与"公司机零联网"冲突。

## 1. P0 — 内核，做完才叫能用

| ID | 功能 | 说明 | 验收 |
|---|---|---|---|
| F1 | **计量内核** | 解析 `~/.claude/projects/**/*.jsonl`；按 `message.id` 去重；时间戳按 UTC 解析后转 +08；三档计价，工作日 9–12、14–18 为峰时 | 与平台账单 5 天误差 ≤ ±8% |
| F2 | **校准** | 默认 ×1.14，可配；界面同时显示「原始估算 / 校准后」；日终录入账单自动重算 | 录入账单后系数自动更新 |
| F3 | **硬顶** | `NORMAL → WARN(70) → WINDDOWN(90) → LOCKED(100)`；LOCKED 后 hook 拒绝新 prompt | 到 100% 时下一次提交被拒 |
| F4 | **收尾豁免** | LOCKED 后仍可提交、跑测试、写交接，独立 0.5 元额度 | 额度内仍可产生请求 |
| F5 | **二级上限** | 默认 20 元，手动启用 + 必填理由 + 记入账本；统计本月次数 | 启用后 18 元告警、20 元锁定 |
| F6 | **状态栏** | Claude Code 状态栏常驻 `work 5.4/10`，70% 黄、90% 红 | 刷新 < 200ms |
| F7 | **CLI** | `wb status` / `tier2` / `report` | 不提供 `today` / `log` |

## 4. 口径约定（写进代码注释，别丢）

1. `timestamp` 是 **UTC 但不带时区**（如 `09/14/2026 09:13:41`）→ `SpecifyKind(Utc)` 再 `+08`；
2. 同一响应在日志里平均重复 **2.3 次**，必须按 `message.id` 去重；
3. `cache_creation_input_tokens` 恒为 0，DeepSeek 不单独收缓存写费；
4. 价格（元/百万 token）：缓存命中 ¥0.02/¥0.04，未命中 ¥1/¥2，输出 ¥4/¥8（谷/峰）；
5. 日志只覆盖约 **88%** 的真实花费，剩余是未落盘的重试 / 后台调用——靠校准系数补，不靠解析。

## 5. 界面结构（Penpot：v0.3 · DSH 侧栏浅色）

宿主是 **DSH 桌面端右侧栏**，所以面板不是固定尺寸的应用，而是侧栏里的一个 tab 正文：

- 宽高填满 pane，内容区可滚动，头部吸顶；
- 顶部四个 tab：今日 / 明细 / 周报 / 设置；
- 宽度自适应，实测两档：360（常规）、300（分栏/窄态，隐藏请求列表只留总量与构成）；
- **浅色主题**，跟随 DSH 明暗设置。

| 画板 | 内容 |
|---|---|
| 01 · 今日 · 360 | 已用/上限、进度条（70%/90% 刻度）、预计用完时间、花费构成、今日请求 |
| 02 · 明细 | 按项目、按模型、未计入部分（12% 校准说明） |
| 03 · 周报 | 本周账单柱状图、与上上周对比、目标达成率 |
| 04 · 设置 | 预算/上限/系数/豁免/峰谷/价目表；录入账单入口 |
| 05 · 二级上限浮层 | 前置条件、理由输入、取消/确认 |
| 06 · 窄态 300 | 窄宽度下的降级布局 |

浅色色板：底 `#FFFFFF`、卡片 `#F5F6F8`、描边 `#E8EAEE`、正文 `#17191E`、次要 `#6B7280`、主色 `#2F6BFF`、警示 `#C2410C`、危险 `#D92D20`、成功 `#067647`。
