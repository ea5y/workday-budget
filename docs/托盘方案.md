# 托盘方案（v0.4）

> 2026-11-04 · 设计稿见 Penpot `v0.4 · 托盘方案 · 2026-11-04`

## 1. 为什么还要托盘

DSH 侧栏面板（v0.3）有个硬约束：**tab 正文要求有前台会话**。而真实工作流是在 Claude Code 终端里敲命令，DSH 不一定开着。

托盘解决的是「**永远能瞄一眼**」：

- 图标本身就是常驻指示器——一根充能条，颜色随额度变化；
- 左键弹出面板，右键出菜单，不打断当前窗口；
- 不依赖任何宿主，DSH 关着也照常工作。

## 2. 两个入口的分工

| 入口 | 场景 | 内容 |
|---|---|---|
| **托盘**（v0.4） | 随时瞄一眼、快速收工 | 今日额度、进度、花费构成、最近请求、收工 |
| **DSH 面板**（v0.3） | 坐下来复盘 | 明细、周报、设置、二级上限 |

两者读**同一份状态文件**，不各算一套账。

## 3. 架构

```
Claude Code ──写──▶ ~/.claude/projects/*.jsonl
                          │ 监听
                          ▼
                   ┌─────────────┐
                   │  wbd 核心   │  常驻，随托盘启动
                   │ 算账 + 状态 │
                   └──────┬──────┘
             ┌────────────┼─────────────┐
             ▼            ▼             ▼
      state.json    托盘 UI        Claude Code hook
      （唯一真相）   （WebView）    （wb check，超限 exit 2）
             ▲
             └── DSH 面板（可选，读同一文件或本地 HTTP）
```

**三条设计红线**：

1. 只有一个算账者（`wbd`），UI 不各自计算；
2. 阻断发生在 hook，不在 UI——UI 关了也必须拦得住；
3. 状态文件是纯本地 JSON，可读可审计，坏了自己删了能重建。

## 4. 技术选型

| 方案 | 体积 | 托盘支持 | 评价 |
|---|---|---|---|
| **Tauri 2（Rust + WebView2）** | ~5–10 MB | 原生 | **推荐**：单文件、启动快、hook 调用 < 50ms |
| Electron | 80–150 MB | 需要库 | 只适合团队已熟 JS 的情况 |
| 纯 Rust（tray-icon + 自绘） | ~2 MB | 原生 | 最轻，但 UI 全手写，不划算 |

核心建议用 **Rust**：`wb check` 是每次提交都要跑的，不能容忍启动一个 Node 运行时。

`WebView2` 在 Win10/11 上通常已存在，缺了再提示安装。

## 5. 文件布局

```
%APPDATA%\workbuddy\
├── config.json      预算 / 系数 / 价目表 / 峰谷 / 暂停记录
├── state.json       今日已花、状态、最后更新时间（UI 与 hook 都读这个）
├── ledger\
│   └── 2026-11.jsonl  逐请求账本（可重建 state）
└── logs\wbd.log
```

`state.json` 示例：

```json
{ "date": "2026-11-04", "spent": 5.40, "cap": 10.00,
  "state": "NORMAL", "requests": 128, "updated": "2026-11-04T14:32:10+08:00",
  "paused": false }
```

## 6. 交互细节

- **图标**：一根充能条，蓝（< 70%）→ 橙（70–90%）→ 红（100%）→ 灰（暂停）；
- **悬停**：`今日 ¥5.40 / 10.00`；
- **左键**：弹出面板（360×520），点外部关闭；
- **右键**：打开面板 / 暂停统计 / 设置 / 退出；
- **暂停统计**：用于休假、开会、排查故障，记一条 pause 到账本，不删数据；
- **置顶小卡**（可选）：240×96，永远置顶，适合双屏。

## 7. 风险

| 风险 | 应对 |
|---|---|
| 托盘与 DSH 面板数据不一致 | 都读 `state.json`，UI 不做二次计算 |
| 公司机不允许开机自启 | 默认不自启，安装时询问；提供纯手动启动 |
| 未签名安装包触发 SmartScreen | 自用可接受；对外分发再签 |
| WebView2 缺失 | 启动检测，给出下载指引 |
| 托盘挂了但以为在统计 | `state.json` 超过 5 分钟未更新 → hook 里降级为"只提示不阻断"并告警 |
