## 如何新增一版

1. 在 Penpot 新建 Page，命名 `vX.Y · 主题 · YYYY-MM-DD`；
2. 若沿用旧稿，从旧 Page **复制** Board 到新 Page，再在新 Page 上修改；
3. 导出 PNG 到 `design/vX.Y/NN-名称.png`；
4. 在上表追加一行，旧行状态改为「已被 vX.Y 取代」；
5. 旧 Page 与旧导出**不删除**。
